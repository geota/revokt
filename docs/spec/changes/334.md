- **#334, `close()` waits for the loader thread:** §5.1 `close()`: after cancelling the loader and awaiting an
  in-flight install, `close()` waits for the loader thread to exit, so no loader thread outlives it. A pool that has
  terminated signals before its worker thread leaves, so awaiting the pool alone let `close()` return while that thread
  was still alive.
