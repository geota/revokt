- **#305:** §6.5 "Seed archive", `seed.json`: `filterFormat` must name the full filter's decoded encoding, else the seed
  is `SEED_UNREADABLE`. The loader checked it only against the engine's formats, so a seed whose header named another
  listed format installed, its header and `meta.json` disagreeing. The writer already writes the full's encoding, and
  a delta may still be in another listed encoding.
