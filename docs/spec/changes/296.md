- **#296, the PKIX fallback's anchor memo and path checks:** §5.1 "PKIX fallback contract": the memo of parsed anchors
  holds the snapshot's `sha256` beside its id, and a snapshot that reuses an id with another `sha256` is parsed again.
  The JDK's empty path for a leaf that is itself an anchor is null, and so is a result in which an element's issuer is
  not the next element's subject under `X500Principal` equality, from the leaf to the anchor.
