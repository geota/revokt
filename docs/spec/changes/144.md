- **#144, the walker fuzzer's properties as the code after #226 meets them:**
  - Test plan §9.1 P2: `Budget ⇒` no leaf key was true by construction; it is now stated on the decision: a
    `PATH_BUDGET_EXCEEDED` decision's keys are empty or the fallback path's one key, which is in `refKeys`.
  - P3 defines "honest" (the world with its world mutations only) and "a limit was hit" (a `Budget` walk or a
    `PATH_BUDGET_EXCEEDED` decision of either world, `FALLBACK_LIMIT` included, which attacker certificates reach by
    taking a chain without a path past `FALLBACK_MAX_PRESENTED`). Where the honest walk is `NotFound` and the mutated
    walk is `Found` under a `Recover(child, CertifiedBy)`, the anchor-certified CA supplied the path that
    `DropIntermediate` or `UnsupportedOwnSig` removed: the walk finds the honest key, and the verdict follows that
    key's CRLite answer instead of the honest world's, in either direction.
  - P8: `UnsupportedOwnSig` and `DropIntermediate` are `NotFound` walks, never `Budget`. `DropIntermediate`'s reason
    is the leaf level's: `NO_CANDIDATE` when the leaf's own issuer was dropped, `UNANCHORED` when a higher
    intermediate was, where the text said `NO_CANDIDATE` for both. The decision is `NO_ISSUER` for a chain of at most
    `FALLBACK_MAX_PRESENTED` certificates and `PATH_BUDGET_EXCEEDED(FALLBACK_LIMIT)` above it, where the text said
    "never `PATH_BUDGET_EXCEEDED`". A world with both is a `NotFound` walk, never `Budget`.
  - §10 residual 16 (new), which follows from #226's `FALLBACK_MAX_PRESENTED`: a walk without a path over more than 8
    presented certificates is `PATH_BUDGET_EXCEEDED(FALLBACK_LIMIT)`, which `DEFAULT` rejects, on a trust-manager
    binding too, since the check runs before `PLATFORM_ONLY`. mozilla::pkix caps the path it builds
    (`MAX_SUBCA_COUNT`, 6 intermediates), not the count presented, so Firefox accepts a padded chain with a short path
    the walker cannot build (an unsupported signature algorithm, a missing intermediate its preload supplies, a
    misclassified honest issuer) that revokt rejects. An anchor-certified CA key holder can turn the rejection into an
    accept (P3's bridge, residual 15).
