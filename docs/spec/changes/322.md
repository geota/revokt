- **#322 (fuzz finding, 2026-11-24), x5u host names:** §7.1's x5u URL grammar and §4's `MozillaRemoteSettings.Builder`
  host rule require each label to start and end with a letter or digit, and the last label to start with a letter,
  where a label could start or end with `-` and the last label could start with a digit. `java.net.URI` reads such an
  authority as registry-based, with no host, so the grammar accepted a host the JDK did not read. The new last-label
  rule covers the old "not all digits nor 0x-hex" one.
