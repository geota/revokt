- **#127, `JvmPlatformTrust`, the PKIX fallback and the read fallback:**
  - §5.1 "PKIX fallback contract": the path lists the presented leaf's exact bytes first, each intermediate as the
    bytes presented for it (its `getEncoded()` only for one found through AIA), and the anchor as the snapshot's bytes
    read for it, which step 6 matches by exact bytes. A leaf `CertificateFactory` rejects, an anchor set none of which
    it reads, and `CertPathBuilderException` are null; a presented intermediate or an anchor it rejects is left out.
    Every other `PKIXBuilderParameters` member is the JDK default, as SunJSSE's `PKIXValidator` leaves it
    (`maxPathLength` 5).
  - §5.1 "Anchor snapshot": a null anchor set or a null anchor, and a set none of whose anchors the parser reads, are
    build failures, `IllegalStateException`, beside a throwing `getAcceptedIssuers()` and an empty set.
  - §4 `AnchorSnapshot`: `sha256` is over the distinct bytes read, sorted as unsigned bytes and concatenated; `anchors`
    keeps the platform's order, duplicates and anchors the parser rejects, and leaves out an anchor whose
    `getEncoded()` throws.
  - §5.3: the default delegate is the default `TrustManagerFactory`'s `X509ExtendedTrustManager` (SunJSSE's on a stock
    JDK), one per `JvmPlatformTrust`; `anchors(d)` reads a null `getAcceptedIssuers()` as the empty set;
    `verifiedChain` is null; the fallback returns an anchor as its bytes read.
  - §10 item 13: the JDK reads the AIA property once, at class initialisation; a fetched issuer comes back as its
    `getEncoded()`, and step 6 applies its rules to it.
  - §3, §4: `PlatformTrust`, `PkixPathBuilderFallback` and `JvmPlatformTrust` are `@RevoktInternalApi` in 0.2.
    `Revokt` wires `JvmPlatformTrust()` itself, and the `platformTrust(…)` builder member is [0.3], public with the
    Android binding, its first consumer.
  - §4 diagnostics: the `IllegalStateException` from `trustManager(delegate)` and `start()` over an unusable anchor set
    is [0.3]; in 0.2 the snapshot build throws it, `start()` succeeds and `Evaluator.evaluate` throws until an index
    exists (§11).
