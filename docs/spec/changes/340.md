- **#340, the public storage:**
  - §3 `RevoktStorage` is public, sealed, built by `inMemory()` and `JvmStorage.directory(…)`; its members are those
    of the `@RevoktInternalApi` `StorageBackend` it wraps, with the `@RevoktInternalApi` `of(backend)` and
    `isInMemory` for revokt's own modules. `OwnershipCheck` and `NewerLayout` are public, in jvmMain beside
    `JvmStorage`.
  - §3 `identity()`: `inMemory()`'s is the instance, so one in-memory value given to two instances throws at the
    second `start()`, as one directory does.
  - §3 the builder default is a fresh `inMemory()` at each `build()`; the `storage` property is null until set.
  - §4 `storage` is a `RevoktStorage?` (Java: `storage(RevoktStorage)`), `JvmStorage.directory(path)` on the JVM.
  - §4 V `IN_MEMORY_STORE_WITH_FETCHING_SOURCE` fires for the default and an explicit `inMemory()` alike, under every
    enforcement, and never for a directory store.
  - test-plan.md (e): a `[0.3]` item for the public storage, and the sweep after a nested root in the `JvmStorage`
    item; the Android instrumented suite asserts the default file system's `unix` view.
