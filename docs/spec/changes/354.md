- **#354, the 0.3 trust manager, sync and state surface:**
  - §11's 0.3 row names the trust-manager surface §4 already specifies: `RevoktTrustManager` (flow steps 0 to 4),
    `RevoktCertificateException`, `sslContext()`, the enforcement and policy setters, `resetState()`, listeners and
    `refreshAnchors()`.
  - §11 and test-plan.md's content-signature bullet drop the [0.3] "restart with the clock behind" item, which no
    fixture carries since `clockBehind` was removed.
  - §4 `start()`: from 0.3 it returns `Unit`, and its diagnostics are only on `state` (`RevoktState.diagnostics` and
    `warnings`).
  - §4 `sync()`: a call that arrives while a sync is queued or running, the start task's first sync included, gets that
    sync's `SyncResult` and queues no sync of its own.
  - §4 `Revokt.evaluate`: `Evaluator.evaluate` advances no `RevoktStatus` counter and emits no event; `Revokt.evaluate`
    counts, emits and runs the shadow as a handshake does.
  - §4 `RevoktListener.onStateChanged` is delivered as the `StateFlow` is: conflated and distinct.
  - §4 `RevoktStatus.unsignedData` is removed: no source produces unsigned data.
  - §4 S sole-seed bullet: the `SEED_UNREADABLE` triple on `state` names `RevoktStateTest`.
  - test-plan.md: a "0.3 API rows" bullet with the rows of `RevoktSyncTest`, `RevoktStateTest`,
    `RevoktTrustManagerTest`, `RevoktStatusTest`, `RevoktListenerTest`, `ShadowPolicyTest` and `RevoktSettersTest`.
