- **#321:** §9.1 Harness raises `-rss_limit_mb` from 1024 to 2560, ClusterFuzz's default for every engine including
  Jazzer: the test JVM's own footprint (1.1 to 1.8 GB with the heap capped at `-Xmx256m`) went over 1024 before any
  input ran, so every nightly target failed as out-of-memory. `-Xmx256m` stays the bound on what one input can
  allocate on the heap. §9.1 Findings: a nightly failure is a finding only when its saved input, replayed alone under
  the harness, fails again and the empty input passes; anything else fails the run without filing an advisory.
